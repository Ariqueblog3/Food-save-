FoodSave wireframe files for GitHub Pages

1. Extract this ZIP file.
2. Open your GitHub repository named MGT4017.
3. Choose Add file > Upload files.
4. Upload index.html, style.css and script.js into the repository root.
5. Commit the changes.
6. Enable GitHub Pages from Settings > Pages, using branch main and folder /(root).

The FoodSave site is a one-page student prototype. Food offers are examples only. The contact form is demo-only and does not send or store messages.
